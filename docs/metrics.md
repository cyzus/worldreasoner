# WorldReasoner Evaluation Metrics

---

## Metric taxonomy

| Layer | Metric | Status |
|-------|--------|--------|
| **Annotation quality** | Inter-rater agreement (κ) | Needs overlap annotation |
| **Annotation quality** | Graph acceptance rate | Needs full annotation |
| **Annotation quality** | Factual error rate | Needs full annotation |
| **Annotation quality** | Annotator–market alignment | ✅ implemented (annotation quality check, ~61% constant) |
| **Hindsight graph quality** | Hindsight event count (per question) | ✅ implemented |
| **Outcome** | Accuracy | ✅ reported (Table 1) |
| **Outcome** | Brier score | ✅ reported (Table 1) |
| **Outcome** | Log score | ✅ reported (Table 1) |
| **Evidence** | Source precision | ✅ reported (Table 2) |
| **Evidence** | Source recall | ✅ implemented — near-zero by design, omitted |
| **Reasoning — retrieval** | Accessible event F1 | ✅ implemented — denominator artifact, omitted |
| **Reasoning — retrieval** | Market-signal recall | ✅ implemented — 41% coverage, 4pp spread, omitted |
| **Reasoning — forecasting** | Future event F1 | ❌ not implemented |
| **Reasoning — forecasting** | Forecast market-direction alignment | ❌ not implemented |
| **Reasoning — combined** | Event F1 | ✅ reported (Table 2) |
| **Reasoning — combined** | Key-event recall | ✅ reported (Table 2) |
| **Reasoning — combined** | Key-event F1 | ✅ implemented, shown in figure |
| **Reasoning — combined** | Key-event precision | ✅ implemented, shown in figure |
| **Reasoning — combined** | Temporal MAE | ✅ implemented — not central, omitted |
| **Reasoning — combined** | Edge recall / precision / direction | ✅ implemented — ~0% coverage, omitted |

**Retrieval vs. forecasting split:** The reasoning metrics above do not yet distinguish between events the agent *could* have retrieved (occurred before simulated date) and events it had to *predict* (occurred after simulated date). This split is the most important unimplemented extension — it would let us measure retrieval quality and causal hypothesization separately.
